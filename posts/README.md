# posts

Each scheduled send lives in a unique dated folder. Never reuse or overwrite the same path.

```
posts/YYYY-MM-DD/post-1/
  manifest.json
  instagram.jpg
  x.jpg
  threads.jpg
  instagram.txt
  x.json
  threads.json
posts/YYYY-MM-DD/post-2/
  ...
```

`manifest.json` status: `ready` | `published`
